## Summary

- The single-flow 1-NMU/1-NSU workload still shows little buffer-depth sensitivity even after the patch. This is plausible because one flow does not create much competing queue pressure.
- 2-hop baseline: avg W/R latency 172.17/157 cycles, achieved W/R bandwidth 2859.84/2860.11 MB/s.
- 16-hop baseline: avg W/R latency 244.46/229 cycles, achieved W/R bandwidth 2036.65/2036.79 MB/s.
- 32-hop baseline: avg W/R latency 322.28/308 cycles, achieved W/R bandwidth 1554.83/1554.91 MB/s.
- All rows returned 0 and tails stayed stable inside each hop group. Hop count remains the dominant factor for this single-flow experiment.
