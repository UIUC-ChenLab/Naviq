# Historical Evaluation Results Inventory

`results_inventory.md` preserves historical organization notes and incomplete
evaluation-result inventories. It is not a maintained experiment campaign, a
reproducible result set, or a source for public performance claims.

Use the manifest-backed `evaluation/`, `validation/`, `hbm/`, `ddr/`, and
`smartnic/` campaigns for release-facing work. Preserve this directory only as
historical context until its material is either reproduced through a manifest
or intentionally removed in a later archival cleanup.
