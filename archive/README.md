# Archived NoC material

This directory preserves historical NoC code, topology inputs, sweep plans,
results, plotting scripts, and analysis notes that are not supported public
entry points. It remains in the repository for review and provenance; its
contents are not built, run by CI, or used by maintained manifests.

Use the maintained locations described in the root README, `src/noc/README.md`,
and `noc_testing/README.md` for new work. Each archive group is recorded in
[`noc/INDEX.md`](noc/INDEX.md), including its former location and replacement
path where one exists.

Do not add new runtime output here. Generated logs, waves, plots, and sweep
results belong in an ignored caller-selected output directory.
